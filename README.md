
# MVP - Gestão de Salão de Beleza

## Descrição
Sistema web desenvolvido para auxiliar na administração de um pequeno salão de beleza.

## Objetivo
Facilitar o cadastro de clientes, o gerenciamento de serviços e o controle de agendamentos, evitando conflitos de horários.

## Tecnologias previstas
- Python 3.12
- Flask
- SQLite
- HTML, CSS e Bootstrap
- SQLAlchemy
- Pytest

## Funcionalidades do MVP
- Cadastro de clientes
- Cadastro de serviços
- Agendamento de atendimentos
- Consulta de agendamentos
- Remarcação de horários
- Cancelamento de agendamentos

## Arquitetura
Aplicação web monolítica organizada no padrão MVC.

## Status
Projeto em desenvolvimento.
